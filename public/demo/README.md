# Demo source image

`product-shoe.jpg` is a Cloudinary sample product image, downloaded from [the Cloudinary demo cloud](https://res.cloudinary.com/demo/image/upload/cld-sample-5.jpg). It is included so the interface can show an example without a new upload, transformation, or image generation call.

This file is demonstration input, not a generated output or an approval decision. The saved reference and evidence are in `fixtures/demo-image.json`. One upload and two Admin API reads completed on October 14, 2026; the delivered original had the same SHA-256 checksum as the bundled file. The sample is retained for reuse. Never put credentials or signed URLs in that fixture.
